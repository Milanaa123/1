# Анимагия — оптимизация (30.10.2026)

## Измерения

Сравнение в Chromium 390 × 844 при deviceScaleFactor=2 (один прогон).

| Операция | До | После |
| --- | ---: | ---: |
| Ввод тестового имени | 424 мс | 40 мс |
| Загрузки одного сегмента animal-data при двух одинаковых поисках | 2 | 1 |
| Автофокус в греческое поле после нажатия кнопки перехода | Да | Нет |

Данный замер не гарантирует аналогичного ускорения на всех телефонах.

## Изменения

1. Переключение шагов не вызывает программный фокус текстовых полей и не поднимает мобильную клавиатуру.
2. Canvas-карточка 1200 × 2000 не перерисовывается на каждый символ при отсутствии нового результата.
3. В памяти вкладки хранится один сегмент данных, но только после успешной проверки SHA-256. Метаданные проверяются заново перед поиском.
4. 275 оригинальных PNG, научный каталог, греческие суммы, оформление и экспорт не изменяются.

Проверка: node --test tests/test_mobile_performance.cjs, а также действующие проверки CI и браузера.
