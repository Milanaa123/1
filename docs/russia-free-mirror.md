- Vercel project: `animagia-free-mirror`, ID `prj_VeerjYCQroMBeZHvvj6Wq959am7j`

## Как работает зеркало

Это **reverse proxy** Vercel на исходный статический сайт Render, а не отдельная копия рисунков. Оно не требует покупки домена и не требует пользователя регистрироваться. Все запросы, включая 400 оригинальных PNG, `data/*.json`, скрипты, страницы и PDF-генератор, проходят по адресу Vercel, поэтому **адрес Render не появляется в адресной строке посетителя**. При обновлениях исходного сайта зеркало сразу получает обновлённое содержимое.

Рабочая конфигурация Vercel (в момент создания загружена как `vercel.json`):

```json
{
  "version": 2,
  "rewrites": [
    {
      "source": "/(.*)",
      "destination": "https://animagia-calculator.onrender.com/$1"
    }
  ]
}
```

Защита доступа Vercel Authentication **отключена** для этого публичного проекта; платный домен и отдельная подписка не оформлялись.

**Важно:** Vercel — только альтернативный путь доступа. Если исходный сайт Render перестанет работать, зеркало тоже перестанет отдавать его содержимое. Возможны бесплатные тарифные лимиты и ограничения доступа у отдельных интернет-операторов; гарантии работы на каждой российской сети нет.

## Для поддержки

Это личный, некоммерческий статический проект. Для изменений оформления, расчётов и рисунков используется оригинальный GitHub + Render. Конфигурация Vercel не хранит изображения или личные имена. По мере необходимости проверять доступность обоих URL именно из российских сетей, прежде чем объявлять полную доступность без VPN.
