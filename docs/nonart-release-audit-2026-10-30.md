## Остаточные ограничения

1. **Нельзя заявлять 100%-й перевод 1,19 млн видов:** независимо подтверждённое русское имя есть только для известной части каталога.
2. **Нельзя заявлять 100%-ю видовую проверку рациона и среды:** без профильного набора источников для каждого вида метки имеют указанную в коде степень обобщения; неизвестное остаётся неизвестным.
3. **PDF пользователя** создаётся через системный диалог печати («Сохранить как PDF»), это не прямой серверный PDF-генератор.
4. Полнота иллюстраций не является частью этой задачи; 275 исходных PNG не тронуты.
