# Stardew Valley RU Tools

Набор инструментов и автоматизаций для работы с русификацией и обработкой модификаций Stardew Valley.

## Назначение проекта

Репозиторий содержит вспомогательные файлы и GitHub Actions workflow для автоматизации задач, связанных с подготовкой русифицированных сборок модов.

## Возможности

- автоматизация обработки файлов модов;
- подготовка переводов и проверок;
- запуск вспомогательных GitHub Actions процессов;
- хранение ссылок и служебных материалов проекта.

## Структура

- `.github/workflows` — сценарии автоматизации GitHub Actions;
- `sve-link.txt` — служебная ссылка проекта;
- `tractor-link.md` — дополнительная информация и ссылки.

## Использование

Проект предназначен для автоматизированных задач в рамках разработки и подготовки модификаций.

## Технологии

- GitHub Actions;
- YAML workflow;
- автоматизация сборки и обработки данных.

## Лицензия

Учебный и вспомогательный проект.
